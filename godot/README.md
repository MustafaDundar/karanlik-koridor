# Karanlık Koridor — Godot 4

Gerçek Godot 4 projesi. Godot 4.3+ ile `project.godot` dosyasını açın ve F6/F5 ile çalıştırın.

**Oyun:** Üç anahtarı topla, koridordaki yaratıktan kaç, yeşil çıkışa ulaş.

**Kontroller:** WASD / ok tuşları hareket ve dönme; Shift koşma; F fener. Telefonda ekrandaki düğmeler kullanılabilir.

**Web:** GitHub Actions iş akışı Godot 4.3 ile Web export yapar. GitHub Pages ayarlarında Source: GitHub Actions seçin.

Bu ilk oynanabilir Godot sürümü prosedürel çizim kullanır. Hugging Face görsel varlıkları henüz dahil değildir.
