# Karanlık Koridor

Godot 4 ile geliştirilen birinci şahıs psikolojik korku oyununun ilk oynanabilir iskeleti.

## Başlatma
1. Godot 4.3+ kur.
2. Bu depoyu indir veya klonla.
3. Godot Project Manager'da `project.godot` dosyasını içe aktar.
4. F6 yerine F5 ile oyunu çalıştır.

## Kontroller
WASD: Hareket • Fare: Bakış • Shift: Koş • F: El feneri • E: Kapı • ESC: Fareyi serbest bırak

## Şu an mevcut
- Prosedürel oluşturulan 3D hastane koridoru
- Birinci şahıs hareket sistemi ve çarpışmalar
- Pil tüketen el feneri
- Atmosferik sis ve titreşen aydınlatma
- Kapı etkileşimi ve bölüm bitirme noktası
